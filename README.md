# 💀 Root-Recon-nmap // Blck0ut.sh
> "Aprenda a sintaxe ou continue nas sombras."

Este projeto não é apenas um script, é um protocolo de treinamento. Ele foi criado para evitar a preguiça e forçar a memória muscular de qualquer estudante de Cyber Security que deseja dominar o **Nmap**.

---

## 🛠️ O Conceito: "Vai digitar para aprender!"

Muitas ferramentas automatizam tudo e deixam o analista "preguiçoso". O script `nmap_root_scan.sh` quebra esse ciclo:
1. Ele apresenta o cenário de reconhecimento.
2. Explica a lógica do comando.
3. **Exige** que você digite o comando manualmente para ser executado.

Se tentar copiar e colar ou errar a sintaxe, o sistema bloqueia.

---

## 🚀 Como Executar o Protocolo

Certifique-se de estar no seu ambiente **Ubuntu/Debian** e siga os comandos:

```bash
# Clone o repositório
git clone [https://github.com/blck0utsh/Root-Recon-nmap.git](https://github.com/blck0utsh/Root-Recon-nmap.git)

# Entre no diretório
cd Root-Recon-nmap

# Dê permissão de execução
chmod +x nmap_root_scan.sh

# Inicie o treinamento
./nmap_root_scan.sh
